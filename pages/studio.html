      Take your game anywhere

      1. Ask a grown-up to help you make a free GitHub account if you're under 13.
        2.

        3. 
            
      3. Go to Settings → Pages, choose the main branch and save. Your game gets its own web address.
        4. 
            
      4. Or host it on Fly.io like PlayTinker does. See Build your own.
        5. 
          
      
          
      Sending projects straight to GitHub from the studio will come with accounts and parent permission.
